# Pterodactyl + Minecraft deployment toolkit

This repository provides a real Pterodactyl Panel development stack plus deployment helpers for a genuine Panel + Wings + Minecraft Java host. It does not pretend a server is running.

## Run the real Panel in GitHub Codespaces

Read [Codespaces setup](docs/CODESPACES.md), rebuild the Codespace, then run:

```bash
bash scripts/start-codespaces-panel.sh
```

This launches the upstream Pterodactyl Panel Docker image with MariaDB and Redis, runs migrations, and prompts you to create the administrator. Open forwarded port 8080. Codespaces is temporary: this starts the real Panel only, not a connected Wings node or public Minecraft server.

## Complete deployment on a supported Linux node

Read [Real deployment guide](docs/REAL-DEPLOYMENT.md).

- `scripts/install-panel-prerequisites-ubuntu-24.04.sh` installs native Panel prerequisites on Ubuntu 24.04.
- `scripts/install-wings-ubuntu.sh` installs Docker, the official Wings binary and a systemd unit on Ubuntu 22.04/24.04.
- Wings requires its own supported Linux node and the exact configuration generated by the Panel.

GitHub Pages cannot run PHP, Docker, Wings or Minecraft. A production deployment needs persistent hosting and reachable network ports.

## Tests

```bash
python -m unittest discover -s tests -v
python tools/check_endpoints.py --help
```

A successful TCP check proves only that a port is reachable; it does not prove Minecraft login works.

## Security

Never commit passwords, API tokens, node tokens, SSH private keys, application keys, `.env` files or `.data/`. Keep the Codespaces port private. Use HTTPS on any production host.
