# Pterodactyl + Minecraft deployment toolkit

This repository contains real installation helpers and deployment documentation for a Pterodactyl Panel + Wings + Minecraft Java deployment. It does **not** pretend a server is running.

## Start here

Read [Real deployment guide](docs/REAL-DEPLOYMENT.md).

- `scripts/install-panel-prerequisites-ubuntu-24.04.sh` installs Panel prerequisites on Ubuntu 24.04.
- `scripts/install-wings-ubuntu.sh` installs Docker, the official Wings binary and a systemd unit on Ubuntu 22.04/24.04.
- Wings still requires a real Linux node and the node configuration/token generated by your own Panel.
- GitHub Codespaces is temporary and is not a supported production Wings host. GitHub Pages cannot run PHP, Docker, Wings or Minecraft.

## Tests

```bash
python -m unittest discover -s tests -v
python tools/check_endpoints.py --help
```

## Endpoint checks

```bash
python tools/check_endpoints.py --panel https://panel.example.com --wings https://node.example.com --mc-host play.example.com --mc-port 25565
```

A successful TCP check proves only that a port is reachable; it does not prove that Minecraft login works.

## Security

Never commit passwords, API tokens, node tokens, SSH private keys, application keys, or `.env` files. Use HTTPS and keep the host updated.
